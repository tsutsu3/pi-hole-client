This guide explains how to get the credential that the app uses to log in to
your Pi-hole server.

- **Pi-hole v5**: use the [API token](#pi-hole-v5-api-token).
- **Pi-hole v6**: use your [web admin password](#pi-hole-v6-password).
  Pi-hole v6 has no API token.

## Pi-hole v5: API token

1. Go to the admin panel of your Pi-hole® server and log in.

   <DocImage priority width="300" alt="login" src={imgLogin} />

2. On the side menu, go to Settings.

   <DocImage width="600" alt="home" src={imgHome} />

3. Go to API / Web interface.

   <DocImage width="600" alt="settings" src={imgSettings} />

4. Click on Show API token.

   <DocImage width="600" alt="web" src={imgWeb} />

5. Click on Yes, show API token.

   <DocImage width="600" alt="yes" src={imgYes} />

6. On the application, tap the QR code button (1) and then, scan the QR code,
   or copy the API token (text under the QR code) and paste it into the Token
   field (2).
   <DocImage width="300" alt="app" src={imgApp} />

## Pi-hole v6: password

Pi-hole v6 has no API token. In the app, enter the password that you use to
log in to the Pi-hole web admin in the **Password** field.

If two-factor authentication (2FA) is enabled, the app also asks for a 6-digit
code. See [Connecting to Your Pi-hole](../create-a-connection/) for details.
