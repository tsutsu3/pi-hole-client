**Pi-hole Client** は、スマートフォンから自身のPi-holeを監視・管理するための非公式Androidアプリです。統計の確認、ブロックの一時停止、最近のクエリの確認、リストの編集など、日常的な管理作業をモバイル向けの使いやすい画面で行えます。

:::note
本アプリはPi-holeチームとは提携していません。

アプリはPi-holeへ**直接**接続します。中継サーバーや第三者のサーバーは使用しません。
:::

## ✅ 対応バージョン

- **Pi-hole v6**：完全対応
- **Pi-hole v5**：旧バージョンとして対応

## 🏠 接続モデル（LAN優先）

このアプリは**ローカルネットワークでの利用**を想定しています。通常は自宅Wi-Fiなどの**LAN内だけ**で使用し、Pi-holeをインターネットへ直接公開することは推奨しません。

- スマートフォンとPi-holeを同じLANまたはVPNに接続します。
- ポートフォワーディングは不要です。
- Pi-holeの**IPアドレス**（例：`http://192.168.1.2/`）または名前解決できるホスト名を使用します。
- 外出先から利用する場合は、**VPN**（WireGuard / Tailscaleなど）を推奨します。HTTPSを使う場合は信頼できる証明書を使用してください。

## ✨ 主な機能

- 📊 ダッシュボード：当日のクエリ数、ブロック率、上位ドメイン・クライアント
- ⏯️ ワンタップでの一時停止・再開（タイマー対応）
- 🔎 多彩なフィルターを備えたクエリログ
- ✅/🚫 許可・拒否リスト、Adlistの更新と適用
- 🖥️ 複数サーバーの登録とすばやい切り替え
- 🔐 HTTP / HTTPS接続（LAN外ではHTTPSを推奨）
- 🎨 Material Youテーマ（Android 12以降）

## 🧰 必要なもの

- 接続可能な **Pi-hole v6またはv5** の環境（同一LAN、VPN、または安全に公開したエンドポイント）

## 🚀 クイックスタート

1. Google Playからインストールするか、GitHubから最新リリースをダウンロードします。
2. **サーバーを追加**します。
   - **v6：**ベースURLとパスワードを入力して保存
   - **v5：**ベースURLとAPIトークンを入力して保存
3. ダッシュボードが表示されることを確認し、10秒間の一時停止を試して操作できることを確認します。

## 🔒 プライバシーとクラッシュレポート

- アプリはPi-holeと**直接**通信します。
- Sentryのレポートは、次の**両方**を満たす場合にのみ送信されます。
  1. **診断情報を送信**が**オン**である
  2. **不具合またはクラッシュ**が発生した
- 送信される情報：スタックトレース、アプリ・OSのバージョン、端末モデル、最小限のコンテキスト
- 送信対象外の情報：Pi-hole APIトークン、クエリ内容、Adlist、個人情報
- **設定 → プライバシー → 診断情報を送信**から、いつでも送信をオフにできます。

## ⚠️ 免責事項

このプロジェクトは**非公式**であり、Pi-holeチームとの提携・支援関係はありません。

LAN外から利用する場合は、VPN、HTTPS、認証などを使用して適切に環境を保護してください。不正アクセスを防ぐため、責任を持って設定してください。
