このガイドでは、アプリをPi-holeサーバーで認証するために必要なAPIトークンの取得方法を説明します。

:::note
この手順は、Pi-holeサーバーのバージョン5.xにのみ適用されます。

Pi-hole 6.xでは認証方法が異なるため、APIトークンは必要ありません。
:::

1. Pi-hole®サーバーの管理画面を開き、ログインします。

   <img width="300" alt="Pi-hole管理画面へのログイン" src={imgLogin.src} />

2. サイドメニューから「Settings」を開きます。

   <img width="600" alt="Pi-hole管理画面のサイドメニュー" src={imgHome.src} />

3. 「API / Web interface」を開きます。

   <img width="600" alt="Pi-holeの設定画面" src={imgSettings.src} />

4. 「Show API token」をクリックします。

   <img width="600" alt="APIトークン表示ボタン" src={imgWeb.src} />

5. 「Yes, show API token」をクリックします。

   <img width="600" alt="APIトークン表示の確認画面" src={imgYes.src} />

6. アプリでQRコードボタン（1）をタップしてQRコードを読み取ります。または、QRコードの下に表示されるAPIトークンをコピーし、「トークン」欄（2）に貼り付けます。

   <img width="300" alt="アプリのトークン入力画面" src={imgApp.src} />
