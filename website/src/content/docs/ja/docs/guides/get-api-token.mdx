このガイドでは、アプリがPi-holeサーバーにログインするための認証情報の取得方法を説明します。

- **Pi-hole v5**：[APIトークン](#pi-hole-v5apiトークン)を使います。
- **Pi-hole v6**：[Web管理画面のパスワード](#pi-hole-v6パスワード)を使います。Pi-hole v6にAPIトークンはありません。

## Pi-hole v5：APIトークン

1. Pi-hole®サーバーの管理画面を開き、ログインします。

   <DocImage priority width="300" alt="Pi-hole管理画面へのログイン" src={imgLogin} />

2. サイドメニューから「Settings」を開きます。

   <DocImage width="600" alt="Pi-hole管理画面のサイドメニュー" src={imgHome} />

3. 「API / Web interface」を開きます。

   <DocImage width="600" alt="Pi-holeの設定画面" src={imgSettings} />

4. 「Show API token」をクリックします。

   <DocImage width="600" alt="APIトークン表示ボタン" src={imgWeb} />

5. 「Yes, show API token」をクリックします。

   <DocImage width="600" alt="APIトークン表示の確認画面" src={imgYes} />

6. アプリでQRコードボタン（1）をタップしてQRコードを読み取ります。または、QRコードの下に表示されるAPIトークンをコピーし、「トークン」欄（2）に貼り付けます。

   <DocImage width="300" alt="アプリのトークン入力画面" src={imgApp} />

## Pi-hole v6：パスワード

Pi-hole v6にAPIトークンはありません。アプリの「パスワード」欄に、Pi-holeのWeb管理画面にログインするときのパスワードを入力します。

2要素認証（2FA）を有効にしている場合は、6桁のコードの入力も求められます。詳しくは[Pi-holeへの接続](../create-a-connection/)を参照してください。
