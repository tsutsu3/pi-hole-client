このセクションは、Pi-hole Clientの画面ごとの使い方を説明する**ユーザーマニュアル**です。各ページでは、画面に表示される内容、そこでできる操作、実際の利用場面での役割を紹介します。

アプリの特定のメニュー項目を確認したい場合は、対応するページを開いてください。

---

## 主な画面

- **[ホーム](./home/)**：Pi-holeの状態をひと目で確認し、ブロックをすばやく一時停止・再開できます。
- **[統計](./statistics/)**：ドメイン、クライアント、サーバーごとに通信の傾向を確認できます。
- **[ログ](./logs/)**：個別のDNSクエリを調べ、ドメインをホワイトリスト・ブラックリストに追加できます。
- **[ドメイン](./domains/)**：許可・拒否ルールを明示的に管理できます。
- **[設定](./settings/)**：アプリの設定、Pi-holeサーバーの管理、詳細オプションの確認を行います。

## ウィジェット

- **[Androidホームウィジェット](./android-home-widget/)**：ホーム画面から状態を確認し、ブロックを切り替えられます。

---

## このマニュアルの使い方

- 初めて使う場合は**ホーム**から始めます。
- 問題を調べるときは**ログ**と**ドメイン**を使用します。
- セットアップ、保守、詳細な操作には**設定**を使用します。

各ページはアプリのUIに沿って説明しているため、アプリを操作しながら確認できます。
